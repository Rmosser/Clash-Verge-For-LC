# Plan Title

复杂、长周期或高风险任务可以复制本模板。普通任务不要求创建计划；计划也不是机器 schema。

## Goal

- 要达到的可观察结果。

## Scope

- 包含的系统、文件或运行环境。
- 明确不包含的高风险或相邻范围。

## Acceptance

- 功能、质量和运行态完成条件。

## Verification

- 可执行的 test、lint、typecheck、build、smoke 或 readback。

## Decisions

- 只记录会影响后续实现或验收的重要取舍。

## Progress

- 需要跨 session 延续时记录当前事实、未完成项和阻塞；不要复制可从 Git 或平台实时读取的状态。
